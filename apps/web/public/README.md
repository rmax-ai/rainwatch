# Synthetic dev snapshot

`forecast.json` here is a SYNTHETIC dev fixture, generated by the real data
pipeline from `packages/test-fixtures/fixtures/rainy-day/` (offline replay,
SPEC §44). It is not live KNMI data. In production this file is replaced by
the published snapshot (SPEC §23-24).

Regenerate from the repo root:

    pnpm --filter @rainwatch/data exec tsx scripts/gen-sample.ts

The web app fetches `/forecast.json`; Vite serves this file from `public/`
during development.
